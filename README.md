# Truth or Dare (18+ Party Game) - v1.1.2

Features:
- **4 Supported Languages**: English, French, Kinyarwanda, Spanish.
- **5 Categories/Modes**: Vanilla, Playful, Wild, Extreme, and Couple Mode.
- **Endless Player Input**: Add unlimited players with gender attributes.
- **Matched Sound & Image Assets**: Fully wired for background music (`.mp3`), sound effects (`.mp3` & `.wav`), and PNG launcher icon.
